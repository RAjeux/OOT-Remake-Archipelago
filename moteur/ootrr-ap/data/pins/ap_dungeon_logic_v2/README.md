# AP dungeon logic revision 2

These generation baselines follow the targeted OOTRR 0.8.2 dungeon-logic
backport at upstream revision `0fa64f44b5e689f39bcf98a151fc32cb019d538e`.
The old files one directory above remain unchanged as historical baselines.
Correcting access requirements changes new placements for a given settings
string and seed; existing generated seed files are loaded directly rather
than regenerated.

`legacy_seed_file.json` is a synthetic compatibility fixture generated by the
published 0.6.0-alpha.1 WASM engine (`7562171dbcf8f9fa114c6f583a3c11661002b9afb6d15b72c51345a2e18b80b7`).
It uses the existing `old_seeds` case `default 0` and its original settings,
including the old-default Ocarina and Kokiri Sword shuffles. Its 178 placements
match the historical digest `c9c420f83cf89aca`. No user's room or save was used.
A regression test requires unchanged parsing, checksum and serialization of
this fixture with the corrected engine.
