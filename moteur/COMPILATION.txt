Engine adapted for Archipelago from GPL-3.0-or-later OOTRR 0.8.1,
commit 3ee77a632fb7c5ed2ccdc33db129f659bc23419f. Original licenses and
attributions are preserved in ootrr-ap/LICENSE, LICENSE-MIT, and NOTICE.

This copy was built with Rust 1.99.0 and the wasm32-wasip1 target.
From ootrr-ap, run:
  cargo build --offline --release --locked --target wasm32-wasip1 -p ootrr-core --bin ootrr_ap
Copy target/wasm32-wasip1/release/ootrr_ap.wasm to
client/ootrr_triforce/engine.wasm in the integration repository.
Running py -3 tools/build.py --engine from the integration root performs
the build and copy, then reassembles the APWorld and client. See the root
README for prerequisites and other build commands.

The added binary is randomizer/core/src/bin/ootrr_ap.rs. Full reachability
sphere generation is in randomizer/core/src/slice/generate.rs.
Python modules, engine.cjs, and engine.wasm are included in the .apworld
and .pyz packages. The APWorld is a ZIP with the .apworld extension and
an ootrr_remake directory; the .pyz is a Python zipapp.
The bundled websockets 13.1 transport retains its BSD license in
websockets/LICENSE. Regression rooms are provided separately in
tests/fixtures/. Game files are supplied locally by the player.
