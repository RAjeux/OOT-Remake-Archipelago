Cette copie a été compilée avec Rust 1.99.0 et la cible wasm32-wasip1.
Depuis ootrr-ap, exécuter :
  cargo build --offline --release --locked --target wasm32-wasip1 -p ootrr-core --bin ootrr_ap
Copier target/wasm32-wasip1/release/ootrr_ap.wasm sous le nom engine.wasm
dans client/ootrr_triforce/ à la racine du projet d'intégration. La commande
py -3 tools/build.py --engine effectue cette compilation et cette copie,
puis reconstruit l'APWorld et le client. Voir le README du projet pour
les prérequis et les autres commandes de construction.
Le binaire ajouté est randomizer/core/src/bin/ootrr_ap.rs. La recherche des sphères complètes se trouve dans
randomizer/core/src/slice/generate.rs. Les fichiers Python et engine.cjs sont dans le .apworld et le .pyz.
L’APWorld est un ZIP portant l’extension .apworld et contenant le répertoire ootrr_remake. Le .pyz est un zipapp
Python. Le transport websockets 13.1 y est fourni sous sa licence BSD (websockets/LICENSE).
Les salles de régression sont fournies séparément sous tests/fixtures/.
